## Пример Integration frontend Tests C2-C3 - без параметров

### Название

Информационный блок Категория отображает сумму кешбэка выбранной категории

### Структура тестовой модели

Feature: Кешбэк -> Story: Категории повышенного кешбэка -> Scenario: Отображение детальной информации

### Атрибуты:

- Layer: Integration Frontend Tests
- Priority: High
- Version: stable

### Описание
Проверка маппинга данных из ответа ручки /bonus/statement в UI компонента детального просмотра. Проверяем, что фронтенд корректно подставляет данные (иконка, название, сумма) в шаблон компонента.

### Предусловие

* Настроена автоподмена для запросов

  * /cat.json
  * rest/personal/souz/endpoint/request/bonus/statement 
* Открыта страница Кешбэк по категориям 
* В подмене для категории Магазины сумма кешбэка за категорию равна 34  

### Шаги

* Нажать на категорию Магазины

### Ожидаемый результат

* Отображается информационный блок Категория
* Название категории в блоке соответствует выбранной категории Магазины 
* Сумма кешбэка за категорию в блоке равна 34 
* В блоке отображается иконка категории Магазины

## Пример Integration frontend Tests C2-C3 - с параметрами

### Название

Время разблокировки в тосте учитывает часовой пояс устройства

### Структура тестовой модели
Feature: Безопасность -> Story: Блокировка входа -> Scenario: Уведомления о блокировке

### Атрибуты:

- Layer: Integration Frontend Tests
- Priority: Medium
- Version: 8.0.0

### Параметры - попарное тестирование

| Часовой пояс до изменения | Часовой пояс после изменения |
| ------------------------- | ---------------------------- |
| UTC+3                     | UTC+5                        |
| UTC+3                     | UTC-5                        |
| UTC+3                     | UTC+3                        |
| UTC+5                     | UTC+3                        |
| UTC+5                     | UTC-5                        |
| UTC+5                     | UTC+5                        |

### Предусловие
- Устройство установлено в выбранный часовой пояс до изменения
- Открыта страница авторизации в ЛКК
- Доступен пользователь для проверки блокировки при вводе некорректного пароля

### Шаги
- Ввести некорректный пароль
- Нажать кнопку Войти
  - Ожидаемый результат шага: 
     - Появился тост с сообщением о блокировке. В тексте уведомления отображается время разблокировки с учетом текущего часового пояса устройства
     - Время разблокировки в тосте соответствует часовому поясу {{Часовой пояс до изменения}}.
- Изменить часовой пояс устройства на {{Часовой пояс после изменения}}
- Нажать кнопку Войти повторно

### Ожидаемый результат
- После изменения часового пояса значение времени в уведомлении соответствует новому часовому поясу устройства
