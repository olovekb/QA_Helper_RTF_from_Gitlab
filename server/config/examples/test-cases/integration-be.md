## Пример Integration Backend Tests C2-C3 - без параметров

### Название
При создании платежа сервис сохраняет запись в базе данных и возвращает идентификатор платежа

### Структура тестовой модели
Feature: Платежный шлюз -> Story: Проведение платежей -> Scenario: Создание успешного платежа

### Атрибуты:
- Layer: Integration Backend Tests
- Priority: High
- Version: stable

### Описание
Проверка основного контракта создания платежа. Тест подтверждает, что при валидном запросе сервис не только отвечает 201, но и сохраняет данные транзакции в основной таблице БД

### Предусловие
- Развернут изолированный стенд payment-service и база данных payment-db
- Таблица payments очищена
- Доступен пользователь user-1001
- user-1001 имеет сумму больше 1000

### Шаги
- Отправить запрос POST /api/v1/payments
  - тело запроса
    - userId: "user-1001"
    - amount - 1000
    - currency: "RUB"
    - purpose: "Оплата услуги"
        - Ожидаемый результат шага: 
           - Статус ответа 201 Created. В теле ответа пришел непустой paymentId. Статус платежа в ответе CREATED
- Получить paymentId из ответа
- Выполнить запрос в базу данных payment-db и найти запись в payments по paymentId

### Ожидаемый результат
В базе данных payment-db существует запись:
 - userId равен "user-1001"
 - amount равен 1000.00
 - currency равен "RUB"
 - status равен "CREATED"
 - createdAt заполнено


## Пример Integration Backend Tests C2-C3 - с параметрами

### Название
Сервис корректно рассчитывает комиссию по тарифу Стандарт

### Структура тестовой модели
Feature: Биллинг -> Story: Калькулятор комиссий -> Scenario: Расчет по тарифным сеткам

### Атрибуты:
- Layer: Integration Backend Tests
- Priority: High
- Version: 1.5.0

### Параметры
| Сумма | Ожидаемая комиссия |
|---:|---:|
| 100 | 2 |
| 500 | 10 |
| 1000 | 20 |
| 2500 | 50 |

### Предусловие
- Развернут изолированный стенд fee-service
- Тариф Стандарт активен и используется по умолчанию
- Расчет комиссии выполняется по правилу 2 процента от суммы

### Шаги
- Отправить запрос POST /api/v1/fees/calc
  - тело запроса
    - amount - {{Сумма}}
    - tariff - Стандарт

### Ожидаемый результат
- Ответ на POST /api/v1/fees/calc
  - статус 200
  - tariff равен Стандарт
  - amount равен {{Сумма}}
  - fee равен {{Ожидаемая комиссия}}
