## Пример E2E Tests C1 - без параметров

### Название
При загрузке бэкапа кабинета применяются настройки кабинета

### Priority
Критический

### Предусловие
- Создан кабинет с 2 группами ролей - обычной и анонимной
- Создан бэкап кабинета с настройками вкладок "Авторизация"

### Шаги
- Общий шаг - Авторизоваться в кабинете провайдера
- Общий шаг - Открыть мастер загрузки бэкапа кабинета
- Выбрать файл бэкапа
- Нажать Далее
   - Ожидаемый результат:
    - Отображается экран сопоставления данных бэкапа
    - Доступны действия Сопоставить группы ролей и Применить
- Оставить способ применения таблиц - Соединить
- Оставить включенным чекбокс Использовать настройки кабинета из файла бэкапа
- Сопоставить группы ролей
- Нажать Применить
   - Ожидаемый результат:
    - Отображается тост с сообщением: "Загрузка прошла успешно."
- Открыть раздел Настройки
- Перейти на вкладку Авторизация

### Ожидаемый результат
- В разделе Настройки - Авторизация
  - выбран тип авторизации - Пароль и подтверждение
  - выбраны параметры - Номер телефона, Электронная почта
  - включен тогл Последовательный ввод данных


## Пример E2E Tests C1 - с параметрами

### Название
На странице операций по категории отображаются выбранный период и список операций

### Priority
Высокий

### Параметры
| Категория | Период |
|---|---|
| Магазины | Текущий месяц |
| Магазины | Предыдущий месяц |
| Кафе | Текущий месяц |
| Кафе | Предыдущий месяц |

### Предусловие
- Подготовлена подмена ответа для запроса получения выписки по бонусам
- В подмене есть операции для категорий Магазины и Кафе за текущий и предыдущий месяц

### Шаги
- Общий шаг - Авторизоваться в мобильном приложении
- Открыть раздел Бонусы
- Открыть Кешбэк по категориям
- Выбрать {{Период}}
- Открыть {{Категория}}

### Ожидаемый результат
- В заголовке страницы операций отображается выбранный период
- Отображается блок "Категория" и значение выбранной категории
- Отображается список операций по выбранной категории за выбранный период
