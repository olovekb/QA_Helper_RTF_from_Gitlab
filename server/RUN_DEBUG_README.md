# 🤖 Автоматическое тестирование и отладка агента

## Быстрый старт

### 1. Запустите сервер
```bash
cd server
npm start
```

Сервер должен запуститься на порту **5002** (или порту из переменной PORT в server.js).

### 2. Запустите отладку (в новом терминале)
```bash
cd server
node run-debug.mjs
```

## Что происходит?

Скрипт `run-debug.mjs` автоматически:
1. ✅ Отправляет тестовые требования на генерацию
2. ✅ Получает тестовую модель (Feature → Story → Scenario → Code)
3. ✅ Получает тест-кейсы (E2E, Integration frontend, Integration backend)
4. ✅ Проверяет 4 критичные правила:
   - Story БЕЗ "проверка|тестирование|api|валидация"
   - Scenario начинается с "нажать|ввести|выбрать|кликнуть"
   - Code БЕЗ префиксов "Frontend:", "Backend:", "UI:", "API:"
   - Expected начинается с "**Отображается**" (с жирным выделением)
5. ✅ Оценивает качество (score 0-100)
6. ✅ Показывает ТОП-5 примеров ошибок с текущим/правильным значением
7. ✅ Показывает ТОП-3 приоритетных исправления
8. ✅ Если score < 80 → ПАУЗА → вы правите промпты → Enter → повтор

## Цель

**Score >= 80 + errors = 0**

## Где править промпты?

Все пути указываются в логах:

```
🔧 ГДЕ ПРАВИТЬ: server.js → buildTestModelPrompt() → ПРАВИЛА STORY
🔧 ГДЕ ПРАВИТЬ: server.js → buildTestModelPrompt() → ПРАВИЛА SCENARIOS  
🔧 ГДЕ ПРАВИТЬ: server.js → buildTestModelPrompt() → ПРАВИЛА CODE
🔧 ГДЕ ПРАВИТЬ: server.js → BASE_SYSTEM_PROMPT → Expected
```

## Критичные проверки

### 1. Story БЕЗ технических терминов
❌ "Проверка валидации формы"
✅ "Заполнение формы задачи"

### 2. Scenario начинается с действия
❌ "Проверить поле Название"
✅ "Нажать кнопку 'Создать'"

### 3. Code БЕЗ префиксов
❌ "Frontend: Отображается поле"
❌ "Backend: Возвращается ответ"
✅ "Отображается поле 'Название'"
✅ "GET /api/v1/tasks с параметрами"

### 4. Expected с жирным выделением
❌ "Отображается поле 'Название'"
✅ "**Отображается** поле 'Название'"

## Troubleshooting

### Ошибка "Connection refused"
Убедитесь, что сервер запущен:
```bash
cd server
npm start
```

### Проверить, что сервер работает
```bash
curl http://localhost:5002/api/debug/validate-model
```

### Изменить порт
Отредактируйте в `run-debug.mjs`:
```javascript
const BASE_URL = 'http://localhost:5002'; // ваш порт
```

## Итеративный процесс

1. Запускаете `node run-debug.mjs`
2. Смотрите логи → видите ошибки
3. Открываете `server.js` → находите нужную секцию промпта
4. Правите промпт (усиливаете запреты, добавляете примеры)
5. Сохраняете `server.js`
6. Перезапускаете сервер (Ctrl+C → `npm start`)
7. Нажимаете Enter в терминале с `run-debug.mjs`
8. Повторяете до score >= 80

## Файлы системы

- `run-debug.mjs` - главный скрипт итеративного тестирования
- `debug-agent.mjs` - валидация и сравнение с эталоном
- `debug-routes.mjs` - API эндпоинты для отладки
- `server.js` - промпты для генерации (здесь править!)
